## 2. 문제 정의

### 2-1. 시장 현황

국내 민간 보험 가입자는 전체 인구의 **약 75%** 수준이며, 1인당 평균 3.2개의 보험을 보유하고 있습니다. 그럼에도 실제 보험금 청구율은 현저히 낮습니다.

> **연간 미청구 보험금 추정액: 2조 원 이상**  
> — 금융감독원 보험 소비자 실태조사 참고

### 2-2. 미청구의 3가지 원인

```
① 복잡성  — 수백 페이지 약관, 어려운 법률 용어
② 귀찮음  — 소액(1~5만원)이라 청구 절차가 더 번거로움
③ 무지    — 특약 존재 자체를 모르거나 보장 범위 불명확
```

### 2-3. 기존 방식의 한계

| 기존 방법 | 문제점 |
|-----------|--------|
| 보험사 앱 | 내 보험만 확인 가능, 비교 불가 |
| 콜센터 상담 | 평균 대기 30분 이상 |
| 보험 설계사 | 영업 목적 개입, 신뢰도 낮음 |
| 직접 약관 검색 | 수백 페이지 중 해당 조항 찾기 불가 |

## 3. 솔루션

### InsurRX의 접근 방식

```
처방전/영수증 사진 1장
        ↓
GPT-4o Vision OCR
(한글·영문·숫자 자동 인식)
        ↓
상병코드 · 약품명 · 금액 구조화
        ↓
Pinecone 벡터 DB 약관 검색
(의미 기반 RAG, 1,358개 조항)
        ↓
GPT-4o 보상 분석
        ↓
청구 가능 여부 + 예상 금액 + 약관 근거
      [3초 이내]
```

### 핵심 차별점

| 항목 | InsurRX | 기존 서비스 |
|------|---------|------------|
| 분석 단위 | 질병코드·약품 단위 정밀 분석 | 진단명 키워드 매칭 |
| 면책 조항 | AI가 비급여·선천성 질환 사전 필터링 | 수동 확인 필요 |
| 약관 근거 | 적용된 조항 원문 인용 | 결과만 제공 |
| 다보험 비교 | 보유 보험 전체 동시 매칭 | 단일 보험사 |
| 속도 | 3초 이내 응답 | 수 분~수십 분 |

## 4. 핵심 기능

### 4-1. Vision OCR

- **엔진**: GPT-4o Vision (gpt-4o-mini)
- **인식 대상**: 진료비 영수증, 처방전, 약품 봉투
- **추출 항목**: 병원명, 진료과, 상병코드(ICD), 처방일, 본인부담금, 약품명·용량·일수, 비급여 항목
- **지원 포맷**: JPEG, PNG, WEBP, HEIC(자동 변환)
- **2단계 파싱**: 정규식 1차 추출 → 누락 시 GPT-4o-mini LLM 보완

### 4-2. RAG 보상 분석

- **Vector DB**: Pinecone (AWS us-east-1, 1,358개 벡터)
- **임베딩**: OpenAI text-embedding-3-small (dim=1536)
- **보유 약관 4종**:

| 약관 | 보험사 | 종류 | 벡터 수 |
|------|--------|------|---------|
| Hi2204 | 현대해상 | 실손의료보험 | 약 350개 |
| Hi2401 | 현대해상 | 암보험 정액형 | 약 480개 |
| My아이플러스 | 삼성화재 | 어린이보험 | 약 390개 |
| 갱신형 2501 | AXA | 치아보험 | 약 138개 |

- **LLM**: GPT-4o (보상 판단·금액 계산·약관 해석)
- **출력**: 청구 가능 여부, 예상 보상 금액, 계산 내역, 약관 조항 원문 인용, AI 신뢰도

### 4-3. Waitlist 이메일 수집

- Railway PostgreSQL 저장 (중복 방지)
- Formspree 폴백 (API 장애 시 자동 전환)
- 선착순 1,000명 → 베타 출시 알림

### 4-4. 카카오톡 채널

- 채널 URL: https://pf.kakao.com/_xmxfjxjX

## 6. 사용자 시나리오

### 메인 플로우 (6단계)

```
STEP 1  사진 입력 방법 선택
        [📷 카메라 촬영] 또는 [🖼️ 갤러리 선택]

STEP 2  이미지 미리보기 확인
        → "AI 분석 시작" 클릭

STEP 3  OCR 분석 중 (평균 3~5초)
        GPT-4o Vision이 처방전 텍스트 추출

STEP 4  인식 결과 확인
        병원명 · 상병코드 · 약품 · 본인부담금 표시
        → "보상 분석 받기" 클릭

STEP 5  보험 선택
        가입 보험 체크박스 선택 (복수 선택 가능)
        → "분석 시작" 클릭

STEP 6  RAG 분석 중 (평균 5~10초)
        Pinecone 벡터 검색 + GPT-4o 보상 판단

STEP 7  분석 결과 리포트
        · ✅ 청구 가능 / ❌ 청구 어려움
        · 예상 보상 금액 (₩ XX,XXX)
        · 계산 내역 (본인부담금 - 공제액)
        · 적용 약관 조항 + 원문 인용
        · AI 신뢰도 %
```

### 엔드투엔드 테스트 결과 (2026-05-26)

```
입력:  급성상기도감염(J06.9), 28,500원, 현대해상 실손 선택
출력:  is_claimable=true
       estimated_payout=18,500원
       공제액: 통원 의원급 10,000원
       confidence=0.9
```
